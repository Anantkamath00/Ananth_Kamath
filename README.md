## Terminal Commands

Open the portfolio and type into the CLI panel:

```
help          → List all available commands
skills        → Display technical skill domains
projects      → List featured security projects
system_scan   → Run a simulated security audit
entropy <str> → Calculate entropy of any string
decrypt       → Trigger CV decryption + download
clear         → Clear terminal output
```
